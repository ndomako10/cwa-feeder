# cwa-feeder — Working Rules

These layer on top of the global CLAUDE.md, which applies in full. See
[README.md](README.md) for what the feeder does.

- **Public repo.** Everything here, history included, is visible to
  anyone. Write for a future contributor: no references to private
  repos, their issues or ADRs, hosts, addresses, people or personal
  details. Deployment notes for a particular setup belong in that
  setup's own repo.
- **Issues are GitHub Issues** on `ndomako10/cwa-feeder`, via `gh`.
- **ADRs** go in `Docs/ADRs/`, written at decision time. The decisions
  that predate this repo (reconciling instead of reacting to imports,
  Calibre's official build over Debian's package, no pip) are described
  in the README and the Dockerfile's comments.
- **Changelog** is generated by git-cliff (`cliff.toml`), committed
  before each release tag.
- **Releases** are `vX.Y.Z` tags on `main`; CI publishes the image.
  Never push a tag before the local checks pass:
  `pre-commit run --all-files`, `pytest`, and the image tests against a
  fresh `docker build`.
- **Python writes LF**: pass `newline="\n"` on every file write.
